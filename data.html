3 条实拍素材 · 各 1 个连续镜头
clip内容时长分段状态
cap-01低照度人物特写8.5s1已接入

一条 clip 记录长这样（字段是最终 schema，值是演示）： 

{
  "clip_id": "cap-01",
  "title": "低照度人物特写",
  "source": "实拍 / interview-clips",
  "video": "assets/caption/cap-01_low-key.mp4",
  "duration_sec": 8.5,
  "resolution": "1280x720",
  "shots": [
    {
      "start": 0.0,
      "end": 3.0,
      "caption": "幽暗林间，蓝发女孩穿暗红上衣，手握螺旋木杖，抬眼看向左前方，神情警觉。",
      "dims": {
        "tone": "冷调",
        "angle": "平视",
        "composition": "中心构图",
        "lighting": "侧光",
        "shot_size": "特写",
        "camera": "固定"
      },
      "evidence_ts": 1.2
    }
  ],
  "annotator": "demo",
  "confidence": "medium",
  "status": "draft"
}
六个维度是固定的：色调、拍摄角度、构图、光影、景别、运镜。 每个镜头每个维度选一个标签；不确定就留空，不猜。 证据时间戳写在 evidence_ts，用来回看判断依据。

case测什么prompt 摘要模型状态

一条 T2V 输出记录长这样；同一 case 下四路视频必须同 prompt、同时长、同分辨率： 

{
  "case_id": "T01",
  "prompt": "夜晚的便利店门口，招牌上写着「24小时营业」，镜头缓慢推近，霓虹灯在湿地面反光",
  "duration_sec": 5,
  "models": ["seedance-2.0", "veo-3.1-fast", "wan-2.6", "kling-2.6"],
  "blind_map": {
    "A": "kling-2.6",
    "B": "seedance-2.0",
    "C": "wan-2.6",
    "D": "veo-3.1-fast"
  },
  "output": {
    "model": "seedance-2.0",
    "path": "data/t2v/T01/seedance-2.0.mp4",
    "resolution": "1080p",
    "seed": 42
  },
  "scores": {
    "text_consistency": 5,
    "quality": 5,
    "structure_stability": 3,
    "motion": 5,
    "aesthetics": 5
  },
  "failure": {
    "type": "text_rendering",
    "evidence_ts": 2.3,
    "note": "第 3 秒「24」的 4 缺一笔"
  }
}
公开数据从哪来：AVGen-Bench 的 13 模型总榜与 failure case 可直接引用； 同 prompt 的四路视频如果缺 Seedance / Wan，就需要自己补生成，不能拿不同 prompt 的视频硬比。

世界模型评测数据

2 个场景 × 3 个模型 = 6 条会话
场景测什么动作脚本模型状态
S02空间记忆绕桌一圈回起点3 路待录屏
S05视角一致性180 度转身再转回3 路待录屏

一条交互会话记录长这样；除了分数，还要存控制日志和同位姿帧： 

{
  "scene_id": "S02",
  "model": "genie-4",
  "session": {
    "resolution": "720p",
    "fps": 24,
    "duration_sec": 42,
    "latency_ms": 180
  },
  "control_log": [
    { "t": 0, "key": "W", "held_sec": 6 },
    { "t": 6, "key": "D", "held_sec": 2 },
    { "t": 8, "key": "W", "held_sec": 4 }
  ],
  "checkpoints": {
    "start_frame": "data/world/S02/genie-4/frames/000.png",
    "return_frame": "data/world/S02/genie-4/frames/420.png"
  },
  "scores": {
    "instruction": 5,
    "physics": 3,
    "camera": 5,
    "memory": 1
  },
  "failure": {
    "type": "memory",
    "evidence_ts": 38,
    "note": "回到起点时红色杯子消失，桌面布局漂移"
  }
}
为什么多存两帧：去程和回程在同一位置各截一帧，才能做“同位姿对照”。 没有这两帧，“记忆一致性”就只能靠感觉，没法复核。
